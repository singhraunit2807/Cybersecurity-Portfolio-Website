OfflineFinder
B.Tech Prototype • Android + BLE

Find a lost device through nearby phones.

A prototype of a crowdsourced offline recovery network. The lost phone can broadcast a temporary BLE identifier; a nearby relay phone can detect it and report the relay phone's location when internet is available.

Ready. This web page is a dashboard/demo; native Android BLE relay requires the Android app.
